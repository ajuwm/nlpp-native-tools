# 07 - A/B：把实机真值接回自研渲染器（第一版）

> **2026-11-14 更新：本文的"真值版"实现已被 `docs/08-PICA光照实现与AB.md` 取代。**
> 第一版把真值塞进旧拟合管线（保留 MATGAIN/out_tint/skin cap、裸 Lambert、眼睛强制 unlit），
> 所以出现用户反馈的"全身过曝发白、眼睛和脸肤色不一致"。根因与按 PICA 硬件语义的重写见 docs/08。

> 目标：把 `docs/06` 读出的**实机真值**（ambient + 2 盏灯）接进自研 CPU 渲染器，
> 与 LPW 现有"按截图拟合"的参数做同场景 A/B。
> 原则：**不改 LPW 主版本**——所有改动只发生在 `nlpp-re/native/`（native 工具的副本）。

## 1. 做法

- 把 `nlpp-native-tools/native/*.py` 复制到 `nlpp-re/native/`（工作副本）。
- 给副本加**多光源真值通道**：
  - `nlp_shade.py`：`LightSet` 支持 `LP_LIGHTS_JSON`（{"ambient":[...],"lights":[{dir,color,spec}]}）；
    新增 `_shade_pixels_multi()`：全局 ambient 只算一次、每盏灯累加漫反射、高光 LUT 用第 1 盏灯。
  - `nlp_render.py`：`draw()` 里把每盏灯的世界方向转换到视空间，传列表给着色。
  - 测试入口 `nlpp-re/native/ab_light.py`、`compose.py`（原样，仅通过环境变量切换光照）。
- 实机真值文件：`out/live/true_lights_env.json`
  ```
  ambient = (0.9765, 0.8980, 0.8980)          # = (249,229,229)/255
  light0  dir=(0.6,0.05,0.7)   color=(0.4,0.698,0.698)   spec=(1.0,0.8,0.8)
  light1  dir=(-0.15,-0.15,-1) color=(0.8,0.698,0.698)   spec=(0.047,0,0.298)
  ```

## 2. 渲染结果（600×860，同一角色/动作/背景）

| 图 | 说明 |
|---|---|
| `out/ab/ab_fitted2.png` | LPW 现有拟合光照（ambient 0.895/0.88/0.86 + 单弱光 0.15） |
| `out/ab/ab_true_iso.png` | **只替换 ambient+灯光真值**（其它实现参数保持默认） |
| `out/ab/ab_toon2.png` | 三渲二路径（`LP_TOONSTYLE=1`，参考用） |
| `out/ab/ab_compare3_compose.png` | 三张并排对比 |

量化（相对 fitted）：真值版 **13.7% 像素变化**、均值差 20.8；
角色区域平均 RGB 从 (157.6,101.2,84.3) 变为 (173.7,122.2,108.5)（更亮、更暖白）。

## 3. 观察与结论

1. **真值与拟合的方向差异明显**：实机 ambient 是 (249,229,229) 暖白，且**两盏灯**
   （一冷一暖，diffuse 0.4/0.7/0.7 与 0.8/0.7/0.7），拟合版只有一盏极弱的顶光。
2. 真值版皮肤明显变亮 → 我们的 PICA 近似实现把"2 盏灯漫反射 + 全局 ambient"直接相加，
   而实机 TEV 里还有材质/LUT/衰减的耦合；**这说明真值已经正确，但实现端还需要
   按 TEV 语义收敛**（下一步：用 `0x1275C0` 的打包细节 + TEV COMB 校正）。
3. 三渲二路径与光照真值无关（用的是手机 shader 移植的 toon ramp），所以它更像"风格选项"，
   不是"实机还原"。

## 4. 复跑

```powershell
# 拟合版
python nlpp-re/native/compose.py --img data/img.bin --w 600 --h 860 --out nlpp-re/out/ab/ab_fitted2.png --bg bs_0000_00_00.jpg
# 真值版（只换光照）
set LP_LIGHTS_JSON=nlpp-re/out/live/true_lights_env.json
python nlpp-re/native/compose.py --img data/img.bin --w 600 --h 860 --out nlpp-re/out/ab/ab_true_iso.png --bg bs_0000_00_00.jpg
# 三渲二
set LP_TOONSTYLE=1
python nlpp-re/native/compose.py --img data/img.bin --w 600 --h 860 --out nlpp-re/out/ab/ab_toon2.png --bg bs_0000_00_00.jpg
```

> 注意：`nlpp-re/native/` 是副本；**LPW 主版本（`nlpp-native-tools/`）未做任何修改**。
