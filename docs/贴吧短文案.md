## B. 推荐版（约 250 字）★

```
【分享】New Love Plus+ 资源解析工具，开源

模型、骨骼、材质、贴图、背景、相机 —— 都能用游戏原生格式直接读出来并正确渲染。

不含任何游戏资源，只放解析器。

· 手臂网格绑的是骨骼 191~224，但绝大多数动作只驱动 12~43，两段几乎不重合
· m_lowerNNN / m_skirt_NNN 这些"下半身/裙摆"层，实际驱动的是【头发骨骼 78~96】
· 找不到"手臂自然下垂"的基础姿势，绑定姿势是 T-pose
· 动作和分层变体的配对规则不在 code.bin 也不在脚本明文里

细节、格式规范、踩过的坑都在仓库里：
https://github.com/ajuwm/nlpp-native-tools

有懂这游戏动画系统的求指点。
```

## C. 带一条具体问题版（约 180 字）

如果想让人一眼看到"能帮上什么"，用这版：

```
New Love Plus+ 解包工具，开源了。
模型/骨骼/贴图/材质/背景/相机都能用原生格式读出来，渲染正确。
https://github.com/ajuwm/nlpp-native-tools

动作 .mot 也解了大半，但卡在一个点上，想问：

手臂网格绑定的是骨骼 191~224，而绝大多数动作只驱动 12~43，两段几乎不重合，
所以手臂一直僵在 T-pose。全库只有 3 个 _10 后缀的动作覆盖完整手臂骨骼，
但套上去角色会形变。

想知道这游戏的动作是怎么分配给骨骼的，或者动作和分层变体（m_upperNNN、
m_lowerNNN、m_skirt_NNN）的配对规则在哪。求指点。
```
